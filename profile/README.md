## Minestead

Minestead is a Minecraft survival server. It's close to vanilla, with no economy and no paid ranks. Players build, explore and trade with each other.

**Play:** `play.minestead.net` · **Website:** [minestead.net](https://minestead.net) · **World archive:** [archive.minestead.net](https://archive.minestead.net)

### What's here

This is where we keep the code behind Minestead.

- [**minestead.net**](https://github.com/minesteadmc/minestead.net): the website and its news posts.
- [**archive.minestead.net**](https://github.com/minesteadmc/archive.minestead.net): a weekly timelapse of the world map, so you can scrub back and watch the world grow.
